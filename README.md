# Staffing Solutions by Sarah Fell Website

Public marketing website for Staffing Solutions by Sarah Fell.

## Scope

- Next.js static export deployed on Vercel.
- Public website assets, pages, and client-side form entry points only.
- Contact, resume, and talent request forms open addressed email drafts.

## Out of Scope

Do not commit private workflow notes, API prototypes, webhook configuration, local agent settings, generated handoff packages, credentials, or scratch design exports to this public repository.

Future backend APIs, automations, and reusable integration code should live in private infrastructure or a private repository before being connected to the public site.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Check

```bash
npm run lint
npm run build
```
